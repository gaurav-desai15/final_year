# Curated seed list for the control-absence mutation corpus.
#
# Real Node/Express applications that ship working route-level access control
# (auth middleware, ownership/role checks) -- so the mutation harness has real
# controls to remove. One repo URL per line; `#` for comments.
#
# `cpgvd corpus collect --from-list corpus/seed_apps.txt` clones each, screens
# the local package.json for express + an auth lib, mutates, and drops any that
# yield < --min-mutations.
#
# This list alone does NOT reach the ~25-app / ~500-instance target -- for that,
# run `cpgvd corpus collect` with GITHUB_TOKEN set (repo search finds hundreds
# of live candidates). This file is the curated core.
#
# Held-out apps (OWASP Juice Shop / NodeGoat) are deliberately absent.
